# Spec — סורק מוכנות-השקה ליזמים → STAGE

מסמך אחד שמרכז את כל ההכרעות. חצי-עמוד לקריאה, השאר רקע. עודכן: 2026-08-05.

---

## בשורה אחת
דף סריקה חינמי שבודק כמה סטארטאפ מוכן להשקה (מהזנת URL, + GitHub אופציונלי),
נותן ציון ופערים, ומזרים את היזם לקהילת **HELIX STAGE** החינמית — ומשם, בעדינות,
לכלים בתשלום שסוגרים לו את הפערים.

## למה עכשיו
- מנוע הסריקה **כבר קיים ורץ** (`helix/lib/geo-scan.ts`, דף `/ai-checker`). לא בונים אוטומציה חדשה — עושים preset + ניתוב.
- ל-HELIX כבר יש קטגוריית "סטארטאפים ויזמים" + הבטחה של STAGE-חינם + 20% הנחה. חסר לזה ראש-משפך.
- זה Bet 2 ([[Strategic-Bets]]) — מקביל ל-Bet 1 (מגנט-AI לעסקים מקומיים), אבל לקהל היזמים.

## ICP — דו-מסלולי (הסורק שואל קודם "השקת כבר?")
| סגמנט | מה הסורק שווה לו | ניתוב ראשי |
|---|---|---|
| טרום-השקה, לא-טכני (הרוב) | ולידציה + ביטחון "אני מוכן?" | STAGE (קהילה/early adopters/פידבק) |
| אחרי-השקה, יש תנועה | "למה לא ממיר / AI לא ממליץ" | Rank / Growth Doctor (בתשלום) — כהמלצה בדשבורד |
| טכני / יש CTO | ניתוח עומק Git | משני — הם יודעים לבד |

## המודל — 3 שכבות, כל אחת בזמן שלה
1. **הסורק** (על helix / דף STAGE): שואל "השקת?", סורק URL (+Git אופציונלי אחרי ה-gate).
   כפתור ראשי **אחד**: "הצטרף חינם ל-STAGE". → **מטרה #1: למלא את הקהילה.**
2. **דשבורד מוכנות בתוך STAGE**: ציון+פערים מאוכלסים מראש + **אזור המלצות** שממפה
   פער→כלי HELIX (כרטיסים + פופאפים), לפי תשובות הסריקה. → **מטרה #2: מוצרים בתשלום, בעדינות (מנגנון PQL — המרה אחרי ערך, לא לפני).**
3. **שיתוף**: הציון + דף המוצר ב-STAGE → וואטסאפ/לינקדאין/פייסבוק, משולב במנגנון
   השיתוף הקיים של STAGE. → **מטרה #3: מודעות/ויראליות.**

הזרימה: שיתוף(3) מביא תנועה → סורק(1) הופך לקהילה → דשבורד(2) ממיר בשלים למשלמים, בלי להבריח את הרוב.

## מדד הצלחה ראשי
לא "כמה לידים" אלא **scan→STAGE-signup**. משני: STAGE→המלצה→ליד-בתשלום (PQL). שלישוני: שיתופים/תנועה.
המשוואה המלאה: תנועה → scan-start → scan→STAGE → activation ב-STAGE → PQL → חבילה בתשלום.

## הבידול (מול עשרות "website graders" חינמיים)
- **Eliminate** ז'רגון טכני · **Reduce** מדדי SEO שכולם נותנים
- **Raise** מוכנות-AI (geo-scan כבר בודק אם ChatGPT/Perplexity ימליצו — כמעט אף grader לא)
- **Create** הממדים שרובוט לא מודד (אונבורדינג/קופי/קהילה) + **אחרי הציון יש לאן ללכת** (קהילה+כלים), לא רק PDF.

## הכרעה ארכיטקטונית פתוחה ❓ (חוסמת את שכבה 2)
הסורק חי ב-repo `helix` (Supabase-scans משלו). STAGE = אפליקציה נפרדת, Supabase נפרד (`helix-stage`).
כדי שהדשבורד יראה את הציון:
- **א.** הסורק רץ *בתוך* STAGE (מעבירים את `geo-scan.ts` ל-`helix-stage`) — נקי, Supabase אחד, משכפל מנוע.
- **ב.** הסורק נשאר ב-helix, ותוצאת הסריקה עוברת ל-STAGE ב-OAuth redirect/webhook — מנוע אחד, גשר בין שני Supabase.

## תוכנית בנייה
- **Phase 1** (helix, מהיר): preset "מוכנות השקה" + שאלת "השקת?" + כפתור→STAGE + שיתוף. שכבות 1+3. נשען על מנוע קיים.
- **Phase 2** (helix-stage): דשבורד מוכנות + אזור המלצות + פופאפים. שכבה 2. תלוי בהכרעה א/ב.
- **Phase 3**: מסלול Git אופציונלי + מדידת המשוואה המלאה.
